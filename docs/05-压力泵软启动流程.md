# 压力泵软件软启动流程

## 1. 适用范围

本文描述 U2 控制器当前已经实现的两路压力泵软启动流程，适用于：

- MOTO1：低压泵；
- MOTO2：高压泵；
- U2 主循环中的压力泵控制状态机；
- U1 通过 `CMD=0x03` 发起压力泵启动、通过 `CMD=0x04` 暂停。

当前实现代码：

- PWM 驱动：[U2/control/Src/moto.c](../U2/control/Src/moto.c)
- PWM 参数：[U2/control/Inc/moto.h](../U2/control/Inc/moto.h)
- 泵控制状态机：[U2/control/Src/uart_command_driver.c](../U2/control/Src/uart_command_driver.c)

## 2. PWM 参数

| 参数 | 数值 | 说明 |
|---|---:|---|
| PWM 载波频率 | 500 Hz | TIM1 输出频率 |
| TIM1 计数频率 | 1 MHz | 系统时钟 24 MHz，预分频为 24 |
| PWM 周期计数 | 2000 | `ARR=1999` |
| 软启动占空比 | 75% | 逻辑值 `750` |
| 持续运行占空比 | 100% | 逻辑值 `1000` |

逻辑占空比范围是 `0~1000`，硬件比较值按下面的公式换算：

```text
CCR = 逻辑占空比 × 2000 / 1000
```

因此：

- `0` -> `CCR=0`，关闭输出；
- `750` -> `CCR=1500`，75% PWM；
- `1000` -> `CCR=2000`，100% PWM。

软启动阶段不是通过 GPIO 延时翻转实现，而是保持 500 Hz PWM 载波，只在阶段切换时改变目标占空比。

## 3. 模式映射

当前协议模式定义如下：

| 模式值 | 协议名称 | 当前泵流程 |
|---:|---|---|
| `0x00` | `RAFT`（皮筏艇/SUP） | 低压泵软启动，再切换高压泵 |
| `0x01` | `AIR_BED`（气垫/充气床） | 普通模式，仅高压泵 |
| `0x02` | `TIRE`（轮胎） | 普通模式，仅高压泵 |

代码通过 `uart_command_pump_uses_low_pressure()` 判断是否使用低压泵流程，目前只有 `UART_COMMAND_MODE_RAFT` 返回真。

如果产品需求把 `AIR_BED` 也定义为低压泵再高压泵，只需要调整这个模式判断函数，其他状态机无需改变。

## 4. 启动命令入口

U1 发送 `CMD=0x03`，载荷为 5 字节：

```text
Byte[0..3]：目标压力，32 位小端，单位 Pa
Byte[4]   ：模式，0=RAFT，1=AIR_BED，2=TIRE
```

U2 接收到命令后依次检查：

1. 电机当前是否允许启动；
2. 目标压力是否大于 0 且不超过协议上限；
3. 模式值是否有效；
4. 压力传感器去皮是否完成。

检查通过后：

1. 保存目标压力和模式；
2. 将 `g_uart_pump_running` 置为运行；
3. 清除上一次泵状态，重新进入 `IDLE`；
4. 立即执行一次泵任务，使软启动从当前命令开始。

重复发送有效启动命令也会重新开始软启动，不会继续沿用上一次启动阶段。

## 5. 普通模式流程

普通模式包括当前的 `AIR_BED` 和 `TIRE` 模式。

### 5.1 时序

```text
IDLE
  │
  ├─ 高压泵：75% PWM，约 6 ms
  ├─ 高压泵：75% PWM，约 6 ms
  ├─ 高压泵：75% PWM，约 6 ms
  ├─ 高压泵：0% PWM，约 5 ms
  │
  └─ 高压泵：100% PWM 持续运行
```

前三个阶段对应“开、开、开”，最后一个阶段对应“关”，四个阶段合计约 `23 ms`。

### 5.2 状态转换

| 状态 | MOTO1 低压泵 | MOTO2 高压泵 | 进入条件 | 下一状态 |
|---|---:|---:|---|---|
| `IDLE` | 0% | 0% | 收到有效启动命令 | `HIGH_KICK` |
| `HIGH_KICK` | 0% | 75%/0% | 软启动阶段运行 | `HIGH_RUN` |
| `HIGH_RUN` | 0% | 100% | 23 ms 阶段结束 | 持续运行 |

## 6. SUP/皮筏艇模式流程

当前代码将 `RAFT(0x00)` 作为 SUP/皮筏艇模式处理。

### 6.1 正常起始压力流程

当启动时实时压力不高于切换压力 `2758 Pa`：

```text
IDLE
  │
  ├─ 低压泵 75% PWM，约 6 ms
  ├─ 低压泵 75% PWM，约 6 ms
  ├─ 低压泵 75% PWM，约 6 ms
  ├─ 低压泵 0% PWM，约 5 ms
  │
  ├─ 低压泵 100% PWM 持续运行
  │       │
  │       └─ 压力 > 2758 Pa
  │
  ├─ 两路泵全部关闭，等待 1000 ms
  │
  ├─ 高压泵 75% PWM，约 64 ms
  ├─ 高压泵 75% PWM，约 64 ms
  ├─ 高压泵 75% PWM，约 64 ms
  ├─ 高压泵 0% PWM，约 64 ms
  │
  └─ 高压泵 100% PWM 持续运行
```

### 6.2 状态转换

| 状态 | MOTO1 低压泵 | MOTO2 高压泵 | 说明 | 下一状态 |
|---|---:|---:|---|---|
| `IDLE` | 0% | 0% | 压力不高于切换压力 | `LOW_KICK` |
| `LOW_KICK` | 75%/0% | 0% | 23 ms 低压软启动 | `LOW_RUN` |
| `LOW_RUN` | 100% | 0% | 低压泵持续充气 | 压力超过 2758 Pa 后进入 `SUP_SWITCH_WAIT` |
| `SUP_SWITCH_WAIT` | 0% | 0% | 两路停止 1 秒 | `SUP_HIGH_KICK` |
| `SUP_HIGH_KICK` | 0% | 75%/0% | 256 ms 高压软启动 | `SUP_HIGH_RUN` |
| `SUP_HIGH_RUN` | 0% | 100% | 高压泵持续运行 | 持续运行 |

### 6.3 启动时已经超过切换压力

如果 SUP/皮筏艇模式收到启动命令时，实时压力已经大于 `2758 Pa`，代码会跳过低压泵阶段，直接进入高压泵 `256 ms` 软启动，然后高压泵持续全开。

这样可以避免在已经达到高压切换条件时再次启动低压泵。

## 7. 软启动阶段的具体分配

### 7.1 普通模式高压泵软启动

总时长为 `23 ms`，分成 4 个阶段：

| 阶段 | 时长 | 泵输出 |
|---:|---:|---|
| 0 | 6 ms | 目标泵 75% PWM |
| 1 | 6 ms | 目标泵 75% PWM |
| 2 | 6 ms | 目标泵 75% PWM |
| 3 | 5 ms | 目标泵关闭 |

### 7.2 SUP 模式高压泵软启动

总时长为 `256 ms`，平均分成 4 个阶段：

| 阶段 | 时长 | 泵输出 |
|---:|---:|---|
| 0 | 64 ms | 高压泵 75% PWM |
| 1 | 64 ms | 高压泵 75% PWM |
| 2 | 64 ms | 高压泵 75% PWM |
| 3 | 64 ms | 高压泵关闭 |

阶段结束后立即切换到目标泵 100% PWM。

阶段截止时间使用绝对 Tick 累加。即使某一轮主循环稍有延迟，也会补齐已经到期的阶段，避免把软启动时间不断拉长。

## 8. 停止和保护流程

以下任一条件成立时，U2 会立即停止两路泵，并清除软启动状态：

1. 收到 `CMD=0x04` 暂停命令；
2. `charge_is_motor_start_allowed()` 不允许电机启动，例如低电保护或 USB/充电策略禁止；
3. 实时压力达到或超过目标压力；
4. `g_uart_pump_running` 被清零；
5. 状态机出现不匹配状态。

停止动作包括：

```text
MOTO1 PWM = 0%
MOTO2 PWM = 0%
状态      = IDLE
软启动阶段计数清零
```

暂停命令只停止当前泵，不改变 U1 的通信协议格式。

## 9. 主循环调用顺序

U2 主循环中，泵流程相关调用顺序为：

```text
usbin_task()
adc_battery_task_100hz(...)
adc_task_100ms()
charge_task()
uart_command_task()
wf183d_task()                 // 使用真实传感器时
uart_command_pump_task()
power_manager_task()
```

`uart_command_pump_task()` 是非阻塞任务，每轮只根据 `HAL_GetTick()` 判断是否需要切换软启动阶段，不会在泵控制流程中长时间阻塞主循环。

## 10. 波形检查要点

使用示波器检查 MOTO1/MOTO2 时，应确认：

- 载波频率约为 `500 Hz`，周期约 `2 ms`；
- 软启动阶段占空比约为 `75%`；
- 普通模式只有 MOTO2 输出，MOTO1 始终为 0%；
- SUP 模式低压阶段只有 MOTO1 输出；
- 低压转高压前，两路同时为 0%，持续约 `1 s`；
- SUP 高压软启动期间只有 MOTO2 输出；
- 软启动完成后目标泵变为 100% 持续输出；
- 暂停或达到目标压力后两路都立即变为 0%。

## 11. 实现边界和待确认项

1. 本流程假设压力泵后级驱动为高电平有效，且 `CCR=0` 表示关闭、`CCR=2000` 表示全开。最终仍应结合实物 MOS 驱动级确认极性。
2. “开、开、开、关”当前解释为 4 个时间阶段：前三段 75% PWM，最后一段 0% PWM；500 Hz 是每个阶段内部的 PWM 载波频率。
3. 当前代码把 `RAFT` 映射为 SUP/皮筏艇低压转高压流程；是否需要把 `AIR_BED` 同样映射到该流程，需要由产品模式定义最终确认。
