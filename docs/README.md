## 一页总览

```mermaid
flowchart LR
    USB[U2 PA5 USB 输入] --> DEB[20 ms 消抖]
    DEB --> CHG[charge_task]
    ADC[U2 电池/电流 ADC] --> LEVEL[BatLevel 0~3]
    CHG --> PROTECT[充电输出与电机保护]
    LEVEL --> PROTECT
    CHG --> CMD2[U2 返回 CMD=0x02]
    LEVEL --> CMD2
    CMD2 --> U1[U1 串口缓存]
    U1 --> ICON[电量图标/充电动画]

    S1[U1 S1 长按] --> SLEEP[CMD=0x05 握手]
    USB --> WAKE[USB 插入唤醒 U2]
    WAKE --> LINK[共享 WK_UP 唤醒 U1]
    SLEEP --> STOP[两颗 MCU 进入 STOP]
    S1 --> LINK2[U1 本地唤醒后 WK_UP 唤醒 U2]
```

## 最重要的约定

1. 电量不是百分比，而是 U2 电池端 ADC 电压分档：`0=满电`、`1=较高`、`2=较低`、`3=低电/空电`。
2. U2 是电池和充电状态的唯一业务来源。U1 只读取 `CMD=0x02`，不读取电池 ADC。
3. 只有“USB 已消抖插入且电流为负”才返回充电中；USB 插入但电流不为负时，U2 仍禁止电机，但协议充电位为 0。
4. U1 图标使用正向“格数”，因此收到 `BatLevel` 后必须计算 `display_level = 3 - BatLevel`。
5. 低电停机和充电期间禁止启动由 U2 本地执行，不依赖 U1 是否在线或是否刚刚轮询到状态。
6. 休眠唤醒有两个本地源：U1 `PA0/S1`、U2 `PA5/USBIN`；两边通过共享 `WK_UP` 线互相通知。
