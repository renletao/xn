# U1 / U2 烧录说明

本文说明 U1 Display 和 U2 Control 的调试器接线、进入烧录状态的方法，以及烧录完成后的上电要求。调试器的 `SWC` 和 `SCLK` 是同一根调试时钟线，部分烧录器标注为 `SWCLK`。

## 1. 调试器接线

烧录器与目标板必须共地，并使用目标板的实际供电电压。建议至少连接以下信号：

| 烧录器信号 | 目标板信号 | U1 Display | U2 Control | 说明 |
|---|---|---|---|---|
| SWDIO / SWD | SWD 数据线 | 首次：PB6 / P01；正常运行：RST / PC0 / P15 | PB6 | U1 的 SWD 数据线由 Option Byte 切换 |
| SWC / SCLK / SWCLK | 调试时钟线 | PA2 / P07 | PA2 | 三个名称指同一根时钟线 |
| RST / NRST | 复位线 | PC0 / P15 | PC0 | 用于复位或连接器的硬件复位 |
| VCC | 目标板电源 | VCC | VCC | 电平必须与目标板匹配 |
| GND | 地 | GND | GND | 烧录器与目标板必须共地 |

U1 的 SWD/NRST 复用由 Option Byte 控制。首次烧录和后续烧录的有效 SWD 数据脚不同，接线时要按当前状态选择：芯片出厂或未运行过本工程程序时使用 `PB6/P01`；程序正常运行后，显示模式会把 `PC0/P15`（板上标为 `RST`）切换为 SWD 数据脚。`SWC` 和 `SCLK` 始终接 `PA2/P07`。

## 2. U1 Display 首次烧录

首次烧录时芯片还没有运行本工程程序，不能依靠 `S3` 进入烧录状态。此时按默认调试复用接线并直接下载：

1. 连接 `SWDIO/SWD` 到 U1 `PB6/P01`，连接 `SWC/SCLK` 到 `PA2/P07`，连接 `RST/NRST` 到 `PC0/P15`，再连接 `VCC` 和 `GND`。
2. 给 U1 上电，在烧录软件中选择硬件复位或连接复位后下载。
3. 直接下载程序并等待校验成功，不需要长按 `S3`。
4. 烧录成功后断电，再重新上电。首次运行时程序会保留约 **5 秒** 的烧录窗口，随后切换到正常显示配置并复位；屏幕在这段时间后才点亮属于正常现象。

## 3. U1 Display 非首次烧录

非首次烧录是指 U1 已经烧录并能够正常运行本工程程序。此时显示模式下的 SWD 数据脚已经切换到板上 `RST/PC0/P15`，因此开始连接时应使用 `RST` 作为 SWD 数据连接，并接好 `SWC/SCLK`、`VCC` 和 `GND`。

1. 给 U1 上电。
2. 长按 `S3`，直到屏幕熄灭。程序会切换到烧录配置并复位，此时有效 SWD 数据脚恢复为 `PB6/P01`。
3. 屏幕熄灭后立即将烧录器的 `SWDIO/SWD` 确认接到 `PB6/P01`，`SWC/SCLK` 保持接在 `PA2/P07`，然后开始下载。
4. 烧录窗口只有 **5 秒**，必须在 5 秒内让烧录器识别芯片并开始烧录；超时后需要重新上电，再次长按 `S3`。
5. 等待烧录器提示校验成功。烧录成功后断电，再重新上电。
6. 新程序第一次上电时屏幕可能约 **5 秒** 后才点亮，这是程序重新切换显示配置的正常现象。

### U1 烧录失败时检查

- 确认 `GND` 已连接，且烧录器与目标板电平一致；
- 确认 `SWC/SCLK` 没有接到普通业务信号；
- 首次烧录使用 `PB6/P01` 作为 `SWDIO/SWD`，不需要按 `S3`；
- 非首次烧录先使用板上 `RST/PC0/P15` 建立连接，再长按 `S3`，熄屏后确认 `SWDIO/SWD` 已接回 `PB6/P01`；
- 超过 5 秒后不要继续尝试，重新上电并再次长按 `S3`；
- 若使用“连接复位后下载”模式，确认烧录器的 `RST/NRST` 已连接到 U1 `PC0/P15`。

## 4. U2 Control 烧录步骤

1. 按上表连接 `SWDIO/SWD`、`SWC/SCLK`、`RST/NRST`、`VCC` 和 `GND`。
2. 连接 U2 的 `RST/NRST`，然后在烧录软件中选择“硬件复位”或“连接复位后下载”。
3. 直接下载 U2 Control 程序，等待烧录和校验完成。
4. 烧录完成后复位 U2；若程序没有自动运行，断电后重新上电。

U2 不需要像 U1 一样通过 `S3` 进入 5 秒烧录窗口。若烧录器无法识别 U2，优先检查 `RST/NRST`、`SWC/SCLK`、`SWDIO/SWD`、`GND` 和目标电源电压。

## 5. 操作注意事项

- 烧录过程中不要同时给同一块板连接多个不同电源；
- `SWC/SCLK` 是时钟线，不能遗漏，也不能与 `SWDIO` 对调；
- U1 长按 `S3` 只用于非首次烧录时切换到烧录配置，不是开始烧录本身；进入窗口后仍需立即在烧录软件中执行下载；
- 修改 U1 的 Option Byte 后必须重新上电验证显示和调试接口，避免在正常显示配置与烧录配置之间停留在错误状态。
