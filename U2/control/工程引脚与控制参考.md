# master 工程引脚控制说明

本文档只说明各引脚的配置方式、有效电平和使用时机，供单独开发和硬件联调时参考。

## 1. 引脚控制总表

| 引脚 | 名称 | 配置方式 | 有效状态 | 什么时候控制 | 功能 |
|---|---|---|---|---|---|
| PA0 | MOTO1 | TIM1_CH1 PWM 输出，AF2 | PWM 高电平有效 | 抵压泵开启时输出 100%；关闭时输出 0 | 抵压泵控制 |
| PA1 | MOTO2 | TIM1_CH2 PWM 输出，AF2 | PWM 高电平有效 | 高压泵开启时输出 100%；关闭时输出 0 | 高压泵控制 |
| PA2 | IP2326_EN | 普通 GPIO 输出 | **高电平开启，低电平关闭** | USB 插入后拉高；USB 拔出后拉低；上电默认拉低 | 快充芯片使能 |
| PA3 | BAT_ADC | ADC 模拟输入 | 读取模拟电压，不分数字高低电平 | 正常运行时周期采样 | 电池电压检测 |
| PA4 | B-_ADC | ADC 模拟输入 | 读取模拟电压，不分数字高低电平 | 正常运行时高频采样；压力泵运行时监测电流 | 电流检测 |
| PA5 | USBIN | GPIO 输入，下拉 | **高电平表示 USB 插入，低电平表示未插入** | 正常运行时持续检测，电平变化时控制 PA2 | USB 插入检测 |
| PA6 | Tx | USART1_TX，AF1 | 串口空闲为高，起始位为低 | 按通信协议向屏驱发送数据 | 屏驱通信 |
| PB5 | SCL/RX | 软件 UART 输入 | 空闲应为高，起始位为低 | 向传感器发送查询命令后接收响应 | WF183D 数据接收 |
| PB0 | MOTO_ADC | ADC 模拟输入 | 读取模拟电压，不分数字高低电平 | 正常运行时周期采样；压力泵运行时可监测过压 | 压力泵电压检测 |
| PB1 | 12V_ADC | ADC 模拟输入 | 读取模拟电压，不分数字高低电平 | 正常运行时周期采样；充电或升压时监测过压 | 12 V 电压检测 |
| PB3 | LED | 普通 GPIO 输出 | 亮灯极性需根据硬件确认 | 打开照明时输出有效电平；关闭时输出无效电平 | 照明灯控制 |
| PB4 | SDA/TX | 软件 UART 输出 | 空闲保持高，起始位拉低 | 查询温度或压力时发送数据，完成后恢复高电平 | WF183D 命令发送 |
| PB7 | WK_UP | GPIO 输入，下拉 | **高电平表示唤醒，低电平表示未触发** | 息屏时持续检测；低到高变化时唤醒屏幕 | 屏幕唤醒检测 |
| PC0 | BAT_COM/Valve | 默认 NRST，释放后才能配置为 GPIO | 当前未定义 | 确定用途和安全电平后才能控制 | 电池图标 COM 或阀预留 |
| PC1 | IP2326_LED | 普通 GPIO 输出 | 亮灯极性需根据硬件确认 | 根据充电、快充或故障状态控制亮灭 | 快充状态灯 |

## 2. 上电时的安全配置

上电时先设置安全电平，再启动通信和采样。

| 引脚 | 上电状态 | 原因 |
|---|---|---|
| PA0、PA1 | 两路 PWM 都为 0 | 防止压力泵误启动 |
| PA2 | 输出低电平 | 默认关闭快充芯片 |
| PA3、PA4、PB0、PB1 | 模拟输入 | 用于 ADC 采样并减少数字输入噪声 |
| PA5 | 输入下拉 | 没有 USB 信号时稳定为低电平 |
| PA6 | USART1_TX 空闲高电平 | 等待发送屏驱数据 |
| PB5 | 输入，空闲高电平 | 等待 WF183D 返回数据 |
| PB3 | 先设置为关灯电平 | 防止照明灯上电闪烁 |
| PB4 | 输出高电平 | 软件 UART 的空闲状态 |
| PB7 | 输入下拉 | 没有唤醒信号时稳定为低电平 |
| PC0 | 保持 NRST | 未确认用途前不要作为 GPIO 使用 |
| PC1 | 先设置为灭灯电平 | 防止状态灯上电误亮 |

PB3 和 PC1 的“灭灯电平”需要根据硬件确定：

- LED 由 GPIO 向外提供电流时，通常高电平点亮、低电平熄灭；
- LED 或三极管由 GPIO 下拉驱动时，通常低电平点亮、高电平熄灭。

## 3. 压力泵引脚控制

PA0 和 PA1 为两个独立的压力泵控制输出，可以分别开启或关闭，也允许同时开启：

| 工作状态 | PA0/MOTO1 抵压泵 | PA1/MOTO2 高压泵 |
|---|---|---|
| 两泵关闭 | 0 | 0 |
| 仅抵压泵开启 | 100% | 0 |
| 仅高压泵开启 | 0 | 100% |
| 两泵同时开启 | 100% | 100% |

PWM 配置参考：

- PWM 频率约为 1 kHz；
- 占空比范围为 0%~100%；
- 0% 表示关闭该方向；
- 50% 表示中等输出；
- 100% 表示压力泵开启时的持续有效电平。

第一次测试时必须确认：

- PA0 输出 100%、PA1 为 0 是否确实开启抵压泵；
- PA0 为 0、PA1 输出 100% 是否确实开启高压泵；
- 两路同时输出 100% 时两个压力泵是否都能正常工作。

## 4. USB 和快充控制

PA5 检测 USB，PA2 控制快充芯片。

### USB 插入

```text
PA5 = 高电平
    -> 判定 USB 已插入
    -> PA2 输出高电平
    -> 开启 IP2326 快充
```

### USB 拔出

```text
PA5 = 低电平
    -> 判定 USB 已拔出
    -> PA2 输出低电平
    -> 关闭 IP2326 快充
```

PA5 配置为下拉输入，因此无信号时默认是低电平。建议每 10~50 ms 读取一次，并连续确认相同电平，避免插拔抖动导致 PA2 频繁切换。

## 5. 屏幕唤醒控制

PB7 配置为下拉输入：

- PB7 为低电平：没有唤醒请求；
- PB7 从低变高：产生一次唤醒请求；
- PB7 保持高电平：表示唤醒信号仍然有效。

息屏时检测到 PB7 从低到高后恢复显示。可以周期轮询，也可以配置为上升沿外部中断。使用中断时，建议进入中断后再次读取引脚电平确认。

## 6. ADC 引脚控制

工程使用 4 个 ADC 输入：

| 引脚 | ADC 通道 | 用途 | 建议采样时机 |
|---|---|---|---|
| PA3 | ADC_IN1 | 电池电压 | 每 100 ms 左右采样一次 |
| PA4 | ADC_IN2 | 电流检测 | 每 10 ms 左右采样一次 |
| PB0 | ADC_IN7 | 压力泵电压 | 每 100 ms 采样；保护用途可提高频率 |
| PB1 | ADC_IN0 | 12 V 电压 | 每 100 ms 采样；保护用途可提高频率 |

ADC 统一配置为 12 位、右对齐、软件触发、单次转换。读取顺序：

```text
选择 ADC 通道
  -> 清除上一次转换完成标志
  -> 启动单次转换
  -> 等待转换完成
  -> 读取 0~4095 的原始值
  -> 换算为电压或电流
```

基础换算：

```text
ADC 引脚电压 = 原始值 x 3.3 / 4095
PA3 电池电压 = ADC 引脚电压 x 11
PA4 电流     = ADC 引脚电压 / 0.1 ohm
```

PA4 的电流换算还需按实际放大器增益、零点和方向校准。PB0、PB1 如果有外部分压，也必须乘以实际分压比例。

## 7. 屏驱通信引脚控制

PA6 配置为 USART1_TX 单向发送：

- 波特率：115200；
- 数据格式：8 数据位、无校验、1 停止位；
- 总线空闲时保持高电平；
- 主控通过 `tx_send()` 向屏驱发送数据；
- 当前 U2 只启用发送方向，屏驱接收端需配置为相同的 115200 8N1。

PA6 不应作为普通 GPIO 随意拉高或拉低。UART 空闲通常为高电平，每个字节由低电平起始位开始。

## 8. WF183D 通信引脚控制

PB4 为软件 UART 发送，PB5 为软件 UART 接收。

### PB4 发送

- 空闲时保持高电平；
- 发送前拉低一个 bit 时间作为起始位；
- 依次发送 8 个数据位，低位先发；
- 最后输出高电平停止位；
- 9600 baud 时每个 bit 约为 104.17 us。

### PB5 接收

- 空闲时应读取到高电平；
- 检测到下降沿后认为起始位到来；
- 延迟半个 bit 后确认起始位；
- 之后每隔约 104.17 us 采样一个数据位；
- 收满 8 位后检查停止位是否为高电平。

发送温度或压力查询命令后，再进入接收状态等待响应。当前工程已实现 9600 8N1 软件串口底层：使用 TIM14 提供微秒级时基，支持阻塞式发送、接收超时和停止位检查。上层仍需根据 WF183D 协议组织查询命令、解析响应并按需实现重试。

## 9. LED 引脚控制

### PB3 照明 LED

- 用户开启照明时输出点亮有效电平；
- 用户关闭照明、系统休眠或发生严重故障时输出熄灭电平；
- 上电时先设置熄灭状态，再切换为输出模式。

### PC1 快充状态 LED

- 未充电时保持熄灭；
- USB 插入并开启快充后可常亮或慢闪；
- 快充故障时可快速闪烁；
- 上电时先设置熄灭状态。

PB3 和 PC1 的点亮极性不能仅从程序确定，必须查看实际原理图或测量驱动电路。

## 10. PC0 使用限制

PC0 默认是芯片复位引脚 NRST。要将它作为电池图标 COM 或阀控制输出，必须先修改 Option Byte，将 NRST 释放为 GPIO。

独立开发前必须先确定：

- PC0 最终连接电池图标还是阀；
- 外部负载是高电平有效还是低电平有效；
- 上电时的安全默认状态；
- 释放 NRST 后如何继续下载和调试程序。

在这些条件未确认前，PC0 应保持复位功能，不要作为普通输出控制。

## 11. 联调注意事项

1. 所有输出引脚应先写入安全默认电平，再切换为输出模式。
2. 压力泵测试应使用限流电源，确认单路和双路开启状态。
3. PA2 的软件定义是高电平开启快充，但仍需确认外部电路没有反相。
4. PA5、PB7 是高电平有效输入，内部下拉不能代替外部抗干扰设计。
5. ADC 输入电压不能超过 MCU 允许范围，12 V 和压力泵电压必须正确分压。
6. PB3、PC1、PC0 的最终有效电平必须以原理图和实测结果为准。
7. PB4/PB5 软件 UART 已完成底层收发；WF183D 是否能正常通信还取决于上层协议、波特率和传感器电平连接。
